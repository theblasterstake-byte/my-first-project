# 請求書メーカー（AI Consultant / 伊藤 剛）

`invoice/index.html` をブラウザで開くだけで動きます。サーバー不要・インストール不要です。

## 使い方
1. `invoice/index.html` をダブルクリック（またはブラウザにドラッグ）で開く
2. 左側のフォームに入力（右側のプレビューが即時に更新されます）
3. 右上の **「PDFで発行」** をクリック → 印刷ダイアログで
   **送信先／プリンター = 「PDFに保存」** を選んで保存
   - 用紙: A4、余白: 「なし」（既定）、背景のグラフィック: ON 推奨

| 消費税 | 10%（固定） |

インボイス登録番号（T番号）は記載していません。

## 自動計算される項目
- **支払期限** … 発行日と同じ月の25日（発行日を入れるだけで反映）
- **金額** … 数量 × 単価
- **小計 / 消費税(10%) / 合計** … 明細から自動集計（消費税は小計に対して10%、円未満切り捨て）

## 毎回入力する項目
宛先会社名、件名、発行日、請求書番号（例：IAI-2026-001）、明細（品目・数量・単位・単価）、備考

## メモ
- 入力内容はブラウザの localStorage に自動保存され、次に開いたときに復元されます。
  まっさらにしたいときは「入力クリア」を押してください。
- 発行日の年を変更すると、請求書番号の年（`IAI-YYYY-連番`）も自動で追従します（連番はそのまま）。
- ファイル構成: `index.html` / `style.css` / `app.js` の3つだけ。外部ライブラリなし。
