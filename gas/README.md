# 議事録管理（共有版）セットアップ手順

Google スプレッドシートをデータの保管場所にして、議事録の画面を Google Apps Script のウェブアプリとして公開します。
発行された URL を開けば、**スマホでも PC でも、相手の端末からでも同じデータを読み書き**できます。

- サーバー契約・ホスティングは不要（すべて Google の無料枠）
- アカウントは**あなたの 1 つだけ**。相手にアカウントを作ってもらう必要はありません
- データはスプレッドシートに 1 行ずつ溜まるので、そのまま並べ替え・集計・バックアップができます

---

## 1. スプレッドシートを作る

1. https://sheets.new を開いて新しいスプレッドシートを作成します。
2. 名前を「議事録」など分かりやすいものに変更します。

シートやヘッダー行は、初回アクセス時にスクリプトが自動で作るので手動で用意する必要はありません。

## 2. スクリプトを貼り付ける（貼り付けは 1 回だけ）

1. スプレッドシートのメニューで **拡張機能 → Apps Script** を開きます。
2. 最初から開いている `コード.gs` の中身をすべて削除します（`Ctrl`（Mac は `⌘`）+ `A` で全選択 → `Delete`）。
3. このフォルダの **`CodeSingleFile.gs`** の中身をすべてコピーして、そこに貼り付けます。
4. フロッピーのアイコン、または `Ctrl`（Mac は `⌘`）+ `S` で保存します。

これだけです。ファイルを追加したり、名前を付けたりする必要はありません（画面の HTML もこのファイルに入っています）。

> `Code.gs` と `index.html` の 2 ファイルに分かれた版も同じフォルダに置いてあります。
> 中身を編集したい場合はそちらが読みやすいので、直したあと `python3 gas/build_single_file.py` を実行すると
> `CodeSingleFile.gs` が作り直されます。動かすだけなら気にしなくて構いません。

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** をクリックします。
2. 歯車アイコン（種類の選択）から **ウェブアプリ** を選びます。
3. 次のとおり設定します。

   | 項目 | 設定値 |
   | --- | --- |
   | 説明 | 議事録管理（任意の文字列） |
   | 次のユーザーとして実行 | **自分**（あなたのアカウント） |
   | アクセスできるユーザー | **全員** |

   「次のユーザーとして実行：自分」にすることで、相手が Google アカウントでログインしなくても、
   あなたのアカウント経由でスプレッドシートに読み書きされます。

4. **デプロイ** をクリックします。初回は権限の確認画面が出ます。
   「このアプリは Google で確認されていません」と表示された場合は、**詳細 → （プロジェクト名）に移動** を選んで許可してください。
   自分で作ったスクリプトなので問題ありません。
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）が、これから使う画面の URL です。

## 4. 使い始める

- URL をブックマークすれば PC からもスマホからも同じ画面が開きます。
- 相手にはこの URL をそのまま送れば共有完了です。相手側でも作成・編集・削除ができます。
- スマホでは、ブラウザの「ホーム画面に追加」をしておくとアプリのように起動できます。

## 画面構成

3 階層をたどる作りになっています。

```
画面1 顧客一覧（メイン画面）
   └ 顧客名をクリック
        画面2 その顧客の議事録一覧（日付が並ぶ）
           └ 日付をクリック
                画面3 議事録（内容の表示 → 編集）
```

### 画面1: 顧客一覧（メイン画面）

- 顧客（会社）ごとに 1 枚のカードが並びます。カードには**最終打ち合わせ日・担当者名・件数**が出ます。
- 並び替えは「最近の打ち合わせ順／会社名順／件数が多い順」。
- 検索は会社名だけでなく、担当者名・議事内容の中身にも当たります（該当する顧客のカードが残ります）。
- 右上の **「＋ 新しい議事録」** から、どの顧客の分でも新規作成できます。

### 画面2: その顧客の議事録一覧

- 日時が新しい順に並びます。各行に**日時・WEB／対面・担当者名・内容の冒頭**が出ます。
- **「＋ この顧客で新規作成」** を押すと、会社名が入力済みの状態で新規作成に進みます。
- 下部の「この顧客の議事録をテキスト書き出し」で、その顧客の分だけまとめて .txt に保存できます。ブラウザ側でダウンロードがブロックされた場合は、コピー用のテキストが画面に表示されます。

### 画面3: 議事録

- 日時・会社名・担当者名・形式・最終更新と、議事内容の全文を表示します。
- **編集する**（同じ画面が入力フォームに切り替わります）／**コピー**（整形テキストをクリップボードへ）／**削除**（確認ダイアログ＋「元に戻す」付き）。
- 入力項目は 日時・会社名・担当者名・WEB／対面・議事内容（自由記入・大きめ）です。会社名は過去に登録した会社の候補が出ます。

### 全画面で共通

- 右上の **「最新に更新」** で、相手や別端末が書いた内容を取り込みます。
- 1 分ごと、および画面に戻ってきたタイミングで自動的に最新化します。**入力中は自動更新を止める**ので、書きかけの内容が消えることはありません。
- 表示中の議事録が別端末で削除されていた場合は、一覧側へ自動的に戻ります。

## 更新のしかた

スクリプトを直したら（`Code.gs` / `index.html` を編集 → `python3 gas/build_single_file.py` → `CodeSingleFile.gs` を貼り直し）、Apps Script の **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** を実行します。
URL は変わらないので、相手に送り直す必要はありません。

## 知っておいていただきたい点

- **URL を知っている人は誰でも読み書きできます。** 相手以外に転送されないようご注意ください。
  URL は推測できない長い文字列なので、共有さえ管理していれば実用上は十分です。
  厳密に制限したい場合は、デプロイ設定の「アクセスできるユーザー」を Google アカウント指定に変更できます（その場合は相手も Google ログインが必要になります）。
- **同じ議事録を同時に編集した場合は、後から保存したほうが残ります。** 別々の議事録なら同時編集で問題ありません。
- **元データはスプレッドシートです。** 誤って消してしまっても、スプレッドシートの「変更履歴」から復元できます。
- Google 側の制限でファイルのダウンロードがブロックされる場合は、スプレッドシートから直接ダウンロード（ファイル → ダウンロード）してください。

## リポジトリ内の他のファイルとの関係

| ファイル | 用途 |
| --- | --- |
| `gas/CodeSingleFile.gs` | 共有版。**Apps Script に貼り付けるのはこれ 1 つだけです** |
| `gas/Code.gs`, `gas/index.html` | 共有版の中身を編集用に分けたもの。直したら `python3 gas/build_single_file.py` で上の 1 ファイルを作り直します |
| `gas/build_single_file.py` | 上記 2 ファイルから `CodeSingleFile.gs` を生成するスクリプト |
| `minutes.html` | 単独版（1 ファイル完結）。ブラウザ内に保存するため、複数人での共有はできません |

単独版はネット接続なしでも動くので、そのまま残してあります。共有版に一本化する場合は削除しても問題ありません。
