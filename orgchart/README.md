# 組織図メーカー

部門名・責任者（役職名＋氏名）・メンバーを入力するだけで組織図を作れるツールです。
`orgchart/index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

## 使い方

1. 左のフォームに **部門名** を入力します（必須）。
2. **上位部門** を選ぶと、その部門の下にぶら下がります。選ばなければ最上位になります。
3. **責任者** の役職名（例: 部長）と氏名を入力します。「＋ 責任者を追加」で部長・課長など複数名を登録できます。
4. **メンバー** は改行・読点（、）・カンマ（,）区切りでまとめて入力できます。
5. 「追加する」を押すと右側の組織図に反映されます。

## 機能

- 部門の階層（何階層でも可）に対応した組織図の自動描画
- 1部門に責任者を複数名登録（入力した順に表示）
- 階層ごとの色分け（同じ段の部門は同じ色、6段で一巡）
- カードまたは部門一覧の「編集」から内容を修正、「削除」で削除
  （削除した部門の配下は自動的に一つ上の階層へ移動します）
- 入力内容は localStorage に自動保存され、次に開いたときも残ります
- メンバー表示のオン／オフ、拡大・縮小
- 「全体表示」で組織図全体が収まる倍率に自動調整、「全画面」で画面いっぱいに表示（Escで終了）
- 左右パネルの間のバーをドラッグして「部門を追加」と「組織図」の幅を変更（ダブルクリックで既定に戻す）
- 組織図エリア右下のつまみで高さを変更（幅・高さは次回も保持されます）
- 「PDF出力」で組織図を A4 1ページの PDF として保存（PDFを保存できない環境では自動的にPNG画像で保存）
- 「印刷」でブラウザの印刷ダイアログを開く（組織図のみが印刷されます）
- JSON の書き出し・読み込みによるバックアップと共有
- 「サンプル読込」で入力例を確認できます
