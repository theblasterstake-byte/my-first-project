# Sales CRM — 営業担当者向け顧客管理ツール

`crm/index.html` をブラウザで開くだけで使えます。ビルド不要・サーバー不要、データはブラウザの
localStorage に保存されます。まず動きを見たい場合は「データ」タブの **サンプルデータを入れる** から。

## 機能

| 画面 | できること |
| --- | --- |
| ダッシュボード | 顧客数／進行中商談額／加重予測（金額×確度）／今月の受注／要フォロー件数、フェーズ別パイプライン、今日のやること、最近の活動 |
| 顧客 | 会社・担当者・連絡先・住所・担当営業・タグ・次回アクション・備考の登録／編集／削除、ステータス別の絞り込み、担当者別の絞り込み、5種類の並び替え |
| 商談 | フェーズ別のカンバン。カードを**ドラッグして別のフェーズへ移動**（確度も自動更新、受注に移すと顧客ステータスも受注へ） |
| 活動履歴 | 電話・メール・訪問・オンライン商談・その他の記録をタイムラインで表示、種別で絞り込み |
| データ | 顧客CSV／商談CSVの書き出し、顧客CSVの取り込み、JSONバックアップと復元、全削除 |

そのほか
- 上部の検索窓で会社名・担当者・メール・電話・住所・タグ・備考をまとめて横断検索
- 顧客カードをクリックすると詳細パネルが開き、そこから活動記録・商談追加・編集・削除
- 次回アクションが期限切れ／当日の顧客は赤・黄で強調
- 削除や取り込みは「元に戻す」で取り消し可能（6秒間）
- スマートフォン表示に対応

## 顧客CSVの形式

1行目はヘッダー行です（`会社名` を含む行があればヘッダーとして読み飛ばします）。

```
会社名,担当者名,役職,電話,メール,ステータス,担当営業,タグ,次回アクション日,次回アクション,備考
株式会社サンプル,山田 太郎,営業部 部長,03-1234-5678,taro@example.co.jp,商談中,自分,製造業 既存顧客,2026-09-01,見積書を送付,決裁者は部長
```

- ステータスは `見込み` `商談中` `受注` `失注` `休眠` のいずれか（未指定・不明な値は `見込み`）
- タグは空白またはカンマ区切り
- 日付は `YYYY-MM-DD`
- 書き出したCSVはUTF-8（BOM付き）なので、Excelでもそのまま開けます

## ファイル構成

```
crm/
├── index.html   画面のマークアップ
├── style.css    デザイン
└── app.js       ロジック（状態管理・描画・CSV/JSON入出力）
```

## URLで使う / 単体ファイルで配る

```bash
node crm/build.js
```

3ファイルを1枚のHTMLにまとめて `crm/dist/` に書き出します。

- `dist/sales-crm.html` — これ1つで動く完全なHTML。メールで送る、USBに入れる、そのままダブルクリックする、といった配り方ができます
- `dist/artifact.html` — claude.ai のArtifactとして公開するための断片

`crm/` をそのままGitHub Pagesなどの静的ホスティングに置けば、`https://<ドメイン>/crm/` でアクセスできます。
`app.js` の `download()` は、直接ダウンロードできないホスティング環境では保存用APIに自動で切り替わるため、
CSV／JSONの書き出しはどちらの環境でも動作します。
