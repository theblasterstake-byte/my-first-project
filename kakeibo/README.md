# レシート家計簿

スマホでレシート・領収書を作成すると、**そのまま家計簿に記録される**ツールです。
HTML / CSS / JavaScript のみで動く単一ページアプリで、ライブラリもサーバーも不要です。

## 使い方

`kakeibo/index.html` をブラウザで開くだけです。
スマホで使う場合は、この `kakeibo/` フォルダを何らかの静的サーバー（GitHub Pages など）に置き、
スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます。

ローカルで試すには:

```sh
cd kakeibo
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## できること

### 作成タブ

- **写真からの自動読み取り（OCR）** — カメラで撮る / 写真を選ぶ / 他アプリの共有メニューから送る /
  画像を貼り付ける / ドラッグ＆ドロップ、のいずれでも読み取りが始まり、
  **日付・店名・合計・明細・税率・カテゴリ**をフォームに自動入力します（下記参照）
- **レシート / 領収書の切り替え** — 領収書では宛名・但し書きを入力できます
- **明細の入力** — 品名・数量・単価を行単位で入力し、小計／消費税／合計を自動計算
- **税率 10% / 8%（軽減）/ 0%**、単価を**税込・税抜**のどちらで入力するかを選択可能
- **伝票の表示・印刷** — レシート風／領収書風に整形して表示。「印刷 / PDF保存」でそのまま発行できます（5万円以上のときは収入印紙欄も表示）
- **レシート写真の添付** — スマホのカメラで撮影して添付。端末内でリサイズしてから保存します
- **カテゴリ・支払方法・メモ**を付けて「家計簿に記録」

## レシートの読み取り（OCR）について

Tesseract.js の日本語モデルを同梱しており、**読み取りはすべて端末内で行われます**。
画像がどこかのサーバーに送られることはありません。

### 使い方

| 方法 | 操作 |
| --- | --- |
| カメラ | 「カメラで撮る」→ その場で撮影 |
| 写真アプリ | 「写真を選ぶ」→ 保存済みの写真を選択 |
| 共有メニュー | 写真アプリなどの共有先にこのアプリを選ぶ（ホーム画面に追加済みの Android Chrome など、Web Share Target 対応環境） |
| 貼り付け | 画像をコピーして、アプリを開いた状態で貼り付け（PC など） |
| ドラッグ＆ドロップ | 画面に画像ファイルをドロップ |

読み取ると次の項目が自動で入ります。**内容は必ず確認してください。**

- 日付（西暦・令和・平成の表記に対応）
- 店名（先頭行から推定）
- 合計金額（「合計」「お会計」などの行を優先。「小計」「お預り」「お釣り」は除外）
- 明細（品名と金額。明細の合計が「合計」か「小計」と一致するときだけ取り込みます）
- 税率と税込／税抜（「小計・消費税・合計」の関係から推定）
- カテゴリ（店名のキーワードから推定）

合計が違っていた場合に備えて、読み取った金額の候補をタップで選び直せます。
うまく読めないときは「もう一度読み取る」か、手で入力してください。
まっすぐ・明るく・レシート全体が入るように撮ると精度が上がります。

初回だけ読み取りエンジン（約 9MB）を読み込みます。以降はキャッシュされるため、
**オフラインでも読み取りが動きます**。自動読み取りは設定タブでオフにできます。

### 明細タブ

- 月ごとに切り替えて、日付グループ単位で一覧表示（日別合計つき）
- 店名・メモ・品名でのキーワード検索、カテゴリでの絞り込み
- タップして詳細を表示 → 伝票の再表示 / 編集 / 削除

### 集計タブ

- 当月の支出合計と**前月比**
- **予算の進捗バー**（設定タブで予算を入れると表示）
- **カテゴリ別のドーナツグラフ**と内訳リスト（金額・割合つき）
- **日別の支出バーチャート**

### 設定タブ

- 1か月の予算、領収書の発行者名・住所、既定の税率
- **CSV書き出し**（Excel 用に BOM つき）
- **JSONバックアップ / 復元**、全データ削除

## データについて

すべてのデータは端末のブラウザの `localStorage`（キー: `kakeibo:v1`）にのみ保存されます。
サーバーには何も送信されません。ブラウザのデータを消すと記録も消えるため、
設定タブから定期的にバックアップしてください。

写真は最大辺 1000px・JPEG 品質 0.65 に縮小してから保存しますが、
`localStorage` の容量（おおむね 5MB 前後）には限りがあります。
使用容量は設定タブに表示され、上限に達したときは保存時に警告を出します。

## 設計メモ

- 本体は `index.html` / `style.css` / `app.js` / `ocr.js`。ビルド不要
- OCR は `vendor/` に同梱した Tesseract.js（Apache-2.0）と日本語モデル（Apache-2.0）。
  CDN へのアクセスはなく、外部への通信は一切ありません
- `manifest.json` と `sw.js` により、ホーム画面に追加してオフラインでも起動可能。
  `share_target` を宣言しているので、共有メニューの送り先になります
- 消費税は日本の小売で一般的な「切り捨て」で計算します
- ダークモードは `prefers-color-scheme` で自動切替
- グラフの配色はカテゴリごとに固定（金額順で色が入れ替わらない）。
  色覚多様性を考慮して検証済みのカテゴリカルパレットを使用し、
  凡例と数値ラベルを常に併記して色だけに依存しないようにしています
