# DESIGN.md — 和栗モンブラン専門店「月と栗」

お店：鎌倉・小町通りから一本入った路地、築90年の古民家。熊本県産の和栗を毎朝ペーストにして、注文後3分以内に搾りたてのモンブランをお出しする。1日80食限定。

美学の方針（雑誌の特集ページのように、静かで上品に）
- 余白をぜいたくに。セクション上下は96px（スマホ64px）、要素の間は32px以上。詰め込まない。
- 区切りは枠線ではなく1pxのヘアライン #e8e3db と余白だけ。影はごく淡く（0 1px 3px rgba(0,0,0,.05)）。
- 色数は絞る。ベース白 #fffdfa、文字 墨 #1f1a16、補助 #6f665e。アクセントは栗色 #6b4423 と月色 #c8a34a の2色のみ。
- 写真は使わず、和栗と月をモチーフにしたCSS/SVGの図形で雰囲気を出す（外部画像を読み込まない）。

文字と配色
- 見出しは明朝（Hiragino Mincho ProN / Yu Mincho / serif）、本文はゴシック（Hiragino Sans / Yu Gothic）。
- 本文18px、補助16px、見出しは h1:44px（スマホ32px）／h2:30px／h3:21px。行間1.9、字間0.04em。
- ダークモード時は背景 #14110e、文字 #f3efe8、ヘアライン #2e2822 に入れ替え、アクセント2色はそのまま使う。

形と動き
- 角丸は控えめに4px（ボタン・カードは8pxまで）。丸すぎるとポップになるので超えない。
- アニメーションは0.3〜0.7秒、ease-out。スクロールで下から10pxふわっと出現、ホバーは線の濃さと1px程度の浮き上がりだけ。
- 検索ヒットは月色の淡い下地でハイライト。派手な点滅はしない。

レイアウトと崩れ防止
- 本文の最大幅は1080px、中央寄せ。カードはグリッドで、スマホは1列に落とす。
- 住所・電話・営業時間は十分な幅を取り1行ずつ縦に並べる。1文字ずつ折り返る極細の列は作らない。
- 管理画面（admin.html）も同じ配色・同じ文字サイズ規則を共有し、表の顔と裏側で世界観をそろえる。
